# 록맨 에그제 3 한글 패치

배틀 네트워크 록맨 에그제 3 **화이트 / 블랙** (일본판 Rev 1, GBA) 한글 패치입니다.

---

## 적용 방법

패치는 **xdelta** 파일입니다. 본인이 가진 ROM 에 직접 적용해서 쓰세요.
**이 배포본에는 ROM 이 들어 있지 않고, 앞으로도 넣지 않습니다.**

1. [xdelta UI](https://www.romhacking.net/utilities/598/) 같은 패치 도구를 준비합니다.
2. **Patch** 에 아래 xdelta 파일, **Source File** 에 원본 ROM 을 지정합니다.
3. 나온 파일을 에뮬레이터나 플래시카트에 올립니다.

| 판 | 패치 파일 | 원본 ROM SHA-256 |
|---|---|---|
| 화이트 | `RockmanEXE3_White_JP_Rev1_KR_v0.9.1.xdelta` | `416aa3d4be363fa3032343c754c924c4d367735dafb5b9158bb2ec234458d2f4` |
| 블랙 | `RockmanEXE3_Black_JP_Rev1_KR_v0.9.1.xdelta` | `f35f6b8a03049e4f23f8cc8c814a846bb5846b21fb8ee24ef40596a9d7554a49` |

원본 ROM 의 해시가 위와 다르면 적용되지 않습니다. **Rev 1** 이어야 합니다.

적용 후 나오는 ROM 의 SHA-256:

| 판 | 패치 적용 결과 SHA-256 |
|---|---|
| 화이트 | `13f0fa3fcd7bf1d607371b24e6a17a8d7c8445f6607f48d871e179dd19a3fd92` |
| 블랙 | `31a632aa16be0269c0f709f73554d9db8be7809d29aca1347a70d24b93fd9528` |

패치 파일은 만든 뒤 **원본에 다시 적용해서 위 해시가 나오는지 확인**한 것만
넣었습니다.

## 무엇이 번역됐나

- **본문 전량** — 스토리·NPC 대사·시스템 메시지·BBS·상점 등 18,010개 문자열
- **칩 / 적 / 내비커스 이름** — 이름표를 용어 정본으로 두고 본문과 통일
- **구운 그래픽** (텍스트가 아니라 그림이라 따로 다시 그린 것들)
  - PET 메뉴 라벨 8개 (칩 폴더 / 서브 칩 / 라이브러리 / 록맨 / E메일 / 키 아이템 / 통신 / 저장)
  - 타이틀 메뉴 (처음부터 / 이어하기)
  - 커스텀 화면 메시지 패널 3종
  - 전투 RESULT 창 (딜리트 타임 / 버스팅 레벨)
  - ROCKMAN 상태 화면 제목과 탭 (록버스터 / 폴더 / 프로그램)
  - P.A. 라이브러리 카운터 (패턴)
  - 폴더 편집의 정렬 메뉴 (이름 / 코드 / 공격력 / 속성 / 개수 / 용량)

화면에서 확인한 범위: 프롤로그, 필드 대사, PET 메뉴 전체, 칩 폴더, 데이터
라이브러리, 록맨 상태, 상점, 전투(칩 선택·적 이름·칩 팝업·도주), 전투 결과 화면,
통신 메뉴 전체.

## 아직 안 된 것 · 알려진 문제

이 패치는 **전체 통과 플레이 검증이 끝나지 않았습니다.** 그래서 v1.0 이 아니라
v0.9.1 입니다.

- **후반부 시나리오·이벤트·엔딩은 눈으로 확인하지 못했습니다.** 게이트는 전부
  통과했지만, 못 가 본 화면에 문제가 남아 있을 수 있습니다.
- **카운터 라벨 한 개가 미번역입니다.** 게임 내부에서 다른 글꼴 뱅크로 그리는
  3글자짜리 라벨인데, 원문을 확정하지 못해 손대지 않았습니다. 숫자와 `MAX`,
  `개` 가 같이 나오는 카운터 화면에서 보일 수 있습니다.
- 작은 탭·패널 머리글 중 아직 못 찾은 **구운 그래픽**이 남아 있을 수 있습니다.

**이상한 화면을 보시면 스크린샷과 함께 이슈로 올려주세요.** 특히 일본어가 그대로
남아 있거나, 글자가 칸을 넘거나, 뜻이 안 통하는 한글이 나오는 경우가 그렇습니다.

## 배포에 관하여

- 이 저장소는 **패치 파일만** 배포합니다. ROM 은 배포하지 않습니다.
- 원작의 모든 권리는 **CAPCOM** 에 있습니다. 이 패치는 비영리 팬 번역이며
  원작을 대체하지 않습니다.
- 재배포는 자유롭게 하시되, 패치 파일을 ROM 에 미리 적용한 형태로는 올리지
  말아주세요.
